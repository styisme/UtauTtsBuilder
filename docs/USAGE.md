# UTAU TTS Voicebank Builder 使用指南

本指南将带你从零开始，熟练使用本工具生成 UTAU / OpenUtau 声库。无论你是初次接触，还是想体验高级功能，都可以在这里找到答案。

---

## 第一章：准备与基础生成

### 1.1 安装与权限
1. 前往 GitHub Releases 页面下载最新的 `UtauTtsBuilder-vX.Y.Z.apk`。
2. 安装并打开 App。首次启动时，系统会要求授予**「文件和媒体」**访问权限，请务必允许，否则无法将生成的声库保存到手机存储中。
3. 建议在设置中允许 App 后台运行（部分国产 ROM 需手动将电池策略设为“无限制”），防止在生成大量音节时被系统杀后台。

### 1.2 基础声库生成（以中文 CV 为例）
1. 回到 App 主页。
2. **声库语言**：选择“中文 CV (78 音节)”。
3. **TTS 引擎**：点击列表，选择一个你的手机自带的 TTS 引擎（例如“科大讯飞”或“系统默认”）。
4. **声库名称**：程序会自动填入引擎名，你可以修改为你喜欢的名字（如“小明”）。
5. **高级参数（可选）**：
   - **语速 / 音高**：建议先用默认值（0.85× / 1.0×）。如果生成的声音太怪，可以尝试微调。
   - **图标 / 立绘**：从相册选择一张 PNG 或 JPG 图片，会自动打包进声库。
6. 点击 **「开始生成声库」**。
7. 弹窗会提示你音节的预计生成时间，点击继续。
8. 等待进度条走完。生成结束后，会弹出一个操作菜单：
   - **查看波形/试听**：可以预览波形并试听音频。
   - **生成 UST 模板**：一键生成 `test.ust`，方便拖入 UTAU 直接试听。
   - **分享 ZIP**：将生成的整个声库打包分享。

### 1.3 声库在哪里？
默认情况下，生成的声库会保存在：
```
内部存储/Download/UtauTtsBuilder/{声库名称}/
```
你可以在系统的文件管理器中找到这个文件夹，将它整个复制到 UTAU 的 `voice` 目录下即可使用。

## 第二章：进阶玩法（右上角 `⋯` 菜单）

在主页右上角有一个 `⋯` 按钮，这里是整个 App 的“生产力工具箱”。

### 2.1 跨语种转换（主页下拉框）
如果你想让**只支持中文**的 TTS 引擎（如某些国产旧版引擎），去唱出**日语**的声音：
1. 在主页的“跨语种转换”下拉框中，选择 **“中 → 日”**。
2. 声库语言照常选择“日语 CV”。
3. 程序会在后台利用拼音/罗马音作为桥梁，将日语发音转换为对应的中文发音交给 TTS 引擎，实现“曲线救国”。
4. 除了中→日，还支持日→中、英→日、智能匹配等 7 种模式。

### 2.2 强制制作（设置页）
如果你选择了“日语”，但你的 TTS 引擎根本没有日语语音包，普通模式下会报错中断。
- 前往 **设置 -> 高级设置 -> 开启「强制制作」**。
- 开启后，如果引擎不支持，程序会自动使用系统默认语言（通常是中文）强制把声音生成出来，避免程序中断。

### 2.3 多引擎批量生成
如果你手机里装了多个 TTS 引擎，想一次性看看它们各自的效果：
1. 点击 `⋯` -> **多引擎批量生成**。
2. 程序会为你当前配置的每一个可用引擎，分别生成一个声库，并自动在名称后加上引擎后缀。

### 2.4 引擎音质对比
1. 点击 `⋯` -> **引擎音质对比**。
2. 程序会让所有可用引擎同时去读一个简短的发音。
3. 完成后，会弹出一个列表，你可以点击不同的引擎，立刻试听它们的音色差异。

### 2.5 声库管理列表
1. 点击 `⋯` -> **已生成的声库**。
2. 这里会列出你在本机生成的所有声库，并显示大小和音节数。
3. 点击某个声库，可以快速分享 ZIP、编辑 `oto.ini` 或直接删除。

### 2.6 运行日志（排查问题必备）
如果生成失败，或者某个功能点不开：
1. 点击 `⋯` -> **运行日志**。
2. 这里记录了 App 所有的底层操作和异常报错。
3. 点击底部的「分享日志文件」，可以通过微信/QQ 发给开发者排查问题。

## 第三章：云端 TTS（可选）

如果你觉得手机自带的 TTS 太机械，可以使用微软 Azure 或 Google Cloud 的高质量云端音色（需要联网，部分服务需自费）。

1. **获取 Key**：
   - **Azure**：在 Azure Portal 创建“语音服务”，获取区域（Region）和密钥（Key）。
   - **Google**：在 Google Cloud Console 启用“Text-to-Speech API”，创建 API Key。
2. **配置**：
   - 进入 App 的 **设置 -> 云端 TTS 配置**。
   - 填入对应的 API Key、区域和音色代码（如 `ja-JP-NanamiNeural`）。
3. **使用**：
   - 回到主页，点击“TTS 引擎”，你会发现列表里多出了 `☁ Azure (...)` 的选项。选中它即可使用。

## 第四章：UI 与个性化定制

在 **设置** 页面，你可以对 App 的外观进行深度定制：
- **外观**：切换浅色、深色或跟随系统。
- **UI 风格**：一键切换 Material 3、鸿蒙 HarmonyOS、Windows UWP、Android 4 Holo 四种复古或现代风格。
- **动态取色**：Android 12+ 支持提取你的壁纸颜色，让 App 界面与你的壁纸融为一体。
- **界面语言**：支持中文、English、日本語三语切换。

## 第五章：常见问题排查（FAQ）

1. **为什么生成出来的声音全是电流音/断断续续？**
   - 系统 TTS 是为了“朗读”设计的，缺乏唱歌的连贯性。建议降低主页的“语速”滑块，或换用更高质量的 TTS 引擎。
2. **为什么生成的声库在 UTAU 里不发声？**
   - 检查你输入的歌词是否与 `oto.ini` 里的别名完全一致（比如我们默认生成的是假名“あ”，你在 UTAU 里必须输入“あ”而不是“a”）。
   - 检查 UTAU 是否加载了你的声库。
3. **在手机上能调教吗？**
   - 生成声库后，可以使用手机端的 OpenUtau 等工具进行简单调教，但复杂的 `oto.ini` 参数微调，强烈建议将 ZIP 传到电脑上，使用 [vLabeler](https://github.com/sdercolin/vlabeler) 或 setParam 进行精细调整。
4. **如何分享生成好的声库？**
   - 生成结束后，点击「分享 ZIP」，或者去 `Download/UtauTtsBuilder/` 目录下找到同名 `.zip` 文件发送给他人。
