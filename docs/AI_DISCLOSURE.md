# AI 生成说明

本项目（**UTAU TTS Voicebank Builder**）在开发过程中大量使用了大型语言模型（LLM）辅助生成代码与文档。本文档详细说明 AI 参与的范围与边界。

## 🤖 AI 参与的部分

以下内容**主要由 AI 生成**，经开发者审阅后纳入项目：

- **架构设计** — 分层结构、模块划分
- **业务逻辑** — 音频处理、oto.ini 生成、reclist 定义
- **平台代码** — Android TTS 调用、云端 API 集成
- **UI 代码** — XAML 布局、页面样式、主题系统
- **本地化** — 三语字符串表
- **文档** — README、CHANGELOG、CONTRIBUTING
- **构建脚本** — GitHub Actions workflow

## 👤 人类参与的部分

以下决策由开发者负责：

- **需求定义** — 要做什么功能、解决什么问题
- **功能验收** — 实际测试并决定是否采纳
- **Bug 定位** — 复现问题、提供日志
- **迭代节奏** — 决定每次发布的改动范围
- **最终发布** — 决定何时发版、是否需要回归测试

## ⚠️ 风险提示

由于大量代码为 AI 生成，可能存在的问题：

- **边缘情况处理不完整** — 某些特殊设备或输入可能崩溃
- **平台兼容性** — 未在所有 Android 版本上充分测试
- **安全性** — 未经过专业安全审计
- **性能** — 未做极限优化
- **依赖更新** — 未跟踪上游 API 变更

## 🙏 建议

- **自用可以**：作为个人工具完全可用
- **商用请谨慎**：建议自行审计代码，或找专业人士复核
- **重要场景**：不要依赖本工具做关键任务
